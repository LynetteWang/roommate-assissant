# roommates-assissant
## 功能总览
### 1. 登录/注册系统
- 手机号/邮箱 + 密码注册登录
- 首次注册后需输入 门牌号 确认舍友身份
- 需阅读并同意 舍友公约 才能进入应用
- 完成后有一个撒花瓣的仪式动画 + "欢迎进入新生活"祝福语
### 2. 账单AA
- 创建账单时输入名称、分类（房租/水电/网费/清洁用品等）、总金额
- 支持 平均分 或 自定义比例 分摊，实时显示每人应付金额
- 账单创建后自动推送给所有同门牌号的舍友
- 每人可独立标记"已付款"，支持全部/待付/已结清/我发起的筛选
### 3. 清洁排班
- 根据舍友作息时间自动生成每周排班表
- 每日分配一人负责公共区域清洁
- 支持 任务清单 （客厅清扫、厨房清洁、垃圾丢弃等），可勾选完成
- 可自定义增删任务、编辑个人作息、重新生成排班
### 4. 舍友公约
- 预置了5章公约（日常作息、财务管理、清洁卫生、访客管理、沟通尊重）
- 可随时编辑修改，修改后需所有人重新签署
- 签字时有一个 Canvas手写签名板 ，签字后触发"一言为定，画押为证"的仪式动画
- 展示所有人的签署状态
### 5. 活动申请
- 发起活动（聚餐/运动/出游/看电影/购物/其他）
- 设置日期、时间、地点、人数上限、描述
- 舍友可自由 加入/退出 活动
- 发起人可结束活动，显示参与人数和头像
### 6. 归家登记
- 提交晚归申请（预计到家时间 + 原因）
- 自动通知同门牌号的所有舍友
- 舍友可点击"我已知晓"确认
- 首页横幅显示"今晚有舍友晚归"提醒，晚归者看到"请放轻脚步"的温馨提示
### 7. 首页 Dashboard
- 时间问候 + 日期
- 快速统计卡片（待付账单/本周清洁/活动/晚归）
- 舍友状态一览（在什么状态）
- 智能待办（未付账单、今日清洁、未读晚归、待加入活动、未签公约）
## 技术说明
- 纯前端实现，使用 LocalStorage 模拟后端数据存储
- 所有数据在浏览器本地保存，关闭后不丢失
- 响应式设计，PC 侧边栏 / 手机底部导航栏自适应
- 暖色调设计风格（sage green + terracotta），营造家的温馨感
使用方式 ：注册3个账号并输入相同的门牌号（如都填`302` ），即可模拟三个舍友的完整合租场景。
